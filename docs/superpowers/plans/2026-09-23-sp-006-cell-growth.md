# SP-006 — růst a přestavba buňky

Výchozí revize: čistá `main`, SP-004/005 zachovány. Používá se stávající TypeScript/Three.js, pnpm a Playwright, bez nových závislostí.

## Postup a kritéria dokončení

1. Volitelný verzovaný stav pouze nové UI linie. Tři prahy skutečně snědené potravy mění fyzické tělo, dosah a kameru; směr a poloha se neztrácejí. Staré kampaně zachovají původní aritmetiku.
2. Velikost omezuje velká sousta a lov. Jehloúst ohrožuje malou buňku, před vyrostlou uhýbá a jde ulovit čelistí. Kontakt úst, ostnů, krunýře a aktivní toxin mají odlišný účinek i čitelnou odezvu.
3. Tři nálezy částí používají záznam původu/generace SP-004, nezávislý na DNA. Objevy se dědí do dalších etap. První růst a nález vedou k placené přestavbě v hnízdě; hlavní nápověda upřednostní tuto smyčku před ekologií.
4. Regrese růstu, velikosti, geometrie kontaktů, odmítnutých akcí, objevů/použití, save/checkpoint a kompatibility SP-004/005. Produkční browser: nová linie, pouze UI/klávesy/RAF, jídlo → tři růsty → objevy → skutečná instalace → export/import. Žádný import připraveného startu, setter ani advanceTime pro tento důkaz.
5. Celá sada, typecheck/build, self-review a nezávislá kontrola změny save kontraktu. Roadmap/report uvádějí původ důkazů a meze včetně chybějícího lidského playtestu. Kompaktní evidence bez trace/video; vlastní mezivýstupy uklidit. Commit a push autorizovány zadáním.
